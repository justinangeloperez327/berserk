# Support

Berserk v1.0.0 provides a stable Rust web framework API.

- Minimum supported Rust version: **1.88**.
- Linux x86_64 is the primary release-validation platform; Windows and macOS receive development compatibility testing.
- Database integration supports PostgreSQL, MySQL, and SQLite when the corresponding features are enabled.
- For security and correctness fixes, use the latest compatible release and test your application against its selected features.
- Breaking public API changes follow semantic versioning.

See the full [support policy](docs/support-policy.md), [known limitations](docs/known-limitations.md), [documentation](docs/index.md), and [security reporting policy](SECURITY.md).
