## Dependency findings

Both findings enter through the optional MySQL driver (mysql 28.0.2):

- [RUSTSEC-2025-0134](https://rustsec.org/advisories/RUSTSEC-2025-0134): rustls-pemfile 2.2.0 is unmaintained. Track the upstream MySQL dependency transition; this is a maintenance warning, not a claim of a known exploitable defect in Berserk.
- [RUSTSEC-2026-0253](https://rustsec.org/advisories/RUSTSEC-2026-0253): lru 0.16.4 has a pop panic-safety defect, fixed in 0.18.2. The stated trigger requires a stored key whose destructor panics. Inspection of mysql 28.0.2's stmt_cache.rs found `LruCache<u32, Entry>`; u32 has no panicking destructor. The reviewed dependency use therefore does not expose that stated trigger. This is a reachability assessment of this call path, not a general guarantee about the dependency. Reassess when MySQL changes its cache types and adopt a compatible upstream fix when available.
