# Berserk v0.6.0

v0.6.0 focuses on database and Claw ORM ergonomics while preserving explicit SQL semantics and bound values.

## Query predicates

The database query builder and Claw now support bound range predicates:

```rust,ignore
let users = User::where_between("score", 50, 100)
    .or_where_not_between("created_at", "2026-01-01", "2026-01-31")
    .get()?;
```

The generated SQL uses placeholders for both bounds. NULL bounds are rejected; use explicit null predicates instead.

Claw also exposes the missing OR variants for list and null predicates:

```rust,ignore
User::where_("active", true)
    .or_where_in("role", ["admin", "owner"])
    .or_where_null("disabled_at")
    .get()?;
```

## Model shortcuts

Model-level helpers mirror the query builder for:

- `where_between` / `where_not_between`;
- `or_where_between` / `or_where_not_between`;
- `or_where_in` / `or_where_not_in`;
- `or_where_null` / `or_where_not_null`.

These are direct typed query constructors, not dynamic method dispatch.

## Migrations

`MigrationRunner::rollback_all` rolls applied batches back from newest to oldest and returns one combined report.

```rust,ignore
let report = runner.rollback_all(&mut connection)?;
```

Each migration remains responsible for explicit `up` and `down` statements.

## Compatibility

- Rust 1.88 remains the MSRV.
- Query values remain bound separately from SQL.
- Existing query and migration APIs remain available.
