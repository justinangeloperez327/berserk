# Berserk v0.7.0

v0.7.0 focuses on application testing ergonomics while keeping tests as normal Rust code.

## HTTP testing

`TestClient` now covers all common request methods, including OPTIONS. `TestResponse` exposes direct inspection helpers:

```rust,ignore
let response = TestClient::new(&app).get("/health")?;

assert_eq!(response.status(), 200);
assert_eq!(response.header("content-type"), Some("application/json"));
assert_eq!(response.text(), "{\"ok\":true}");
```

Fluent assertions include:

- `assert_redirect(location)`
- `assert_client_error()`
- `assert_server_error()`
- `assert_text_contains(...)`
- `assert_json_path_missing(...)`
- existing status, header, body, JSON, validation, authentication, and authorization assertions.

## Recorders and fakes

`EventRecorder` can inspect the most recent event and clear recorded history. `JobProbe` exposes the last recorded attempt. `FakeHttpClient` can report and drain recorded outbound requests.

These helpers make assertions explicit without introducing hidden global test state.

## Compatibility

- Rust 1.88 remains the MSRV.
- Existing test APIs remain available.
- Production application APIs are unchanged by this release.
